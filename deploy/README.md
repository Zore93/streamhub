# StreamHub — Ubuntu 24.04 Deployment Package

Production-ready single-command deployment of the entire StreamHub platform
(React frontend, FastAPI backend, MongoDB, Nginx reverse proxy, Let's Encrypt
TLS, FFmpeg, systemd auto-start) on a fresh Ubuntu 22.04 / 24.04 server.

## Contents

| Path                          | Purpose                                                            |
| ----------------------------- | ------------------------------------------------------------------ |
| `docker-compose.yml`          | Orchestrates mongo, backend, frontend, nginx, certbot              |
| `Dockerfile.backend`          | FastAPI image (Python 3.11 + FFmpeg)                               |
| `Dockerfile.frontend`         | React build → Nginx static server                                  |
| `.env.example`                | All environment variables, documented                              |
| `nginx/streamhub.conf.template` | Reverse proxy + SSL + WebSocket + large upload bodies            |
| `nginx/ssl-params.conf`       | Modern TLS profile + HSTS                                          |
| `scripts/install.sh`          | One-shot installer (Docker, certs, stack, systemd, UFW)            |
| `scripts/reset-admin.sh`      | Reset the admin password on a live deployment                      |
| `scripts/backup-mongo.sh`     | Dump MongoDB to `./backups/<timestamp>/`                           |
| `streamhub.service`           | systemd unit (installed automatically)                             |

## 1. Prerequisites

- Fresh **Ubuntu 22.04 / 24.04 LTS** (≥ 2 vCPU, ≥ 4 GB RAM, ≥ 20 GB disk).
- Domain name with **A record** pointing to the server's public IP.
- Root SSH or sudo access. Ports **80/443/22** open at the provider firewall.

## 2. One-command install

```bash
git clone https://github.com/YOUR-ORG/streamhub.git /opt/streamhub
cd /opt/streamhub
sudo bash deploy/scripts/install.sh
```

The installer will **prompt** for:

1. `DOMAIN` — the public hostname (DNS must already resolve).
2. `ADMIN_EMAIL` — the seeded admin account.
3. `ADMIN_PASSWORD` — its initial password (change later in the UI).

Everything else is auto-generated (Mongo root password, JWT secret, etc.).

When it finishes you'll see:

```
StreamHub is live — https://your-domain.example.com
Admin panel:   https://your-domain.example.com/admin

MongoDB credentials (also written to deploy/.env):
  Host:     127.0.0.1  (loopback only)
  Port:     27017
  Database: streamhub
  User:     shadmin
  Password: <auto-generated>
  Auth DB:  admin
```

## 3. What the installer does

1. Verifies Ubuntu version and updates apt.
2. Installs base packages + **Docker Engine + Compose plugin**.
3. Configures **UFW** to allow `22/tcp`, `80/tcp`, `443/tcp` (and `ufw enable`).
4. Verifies DNS A record for `$DOMAIN` resolves to this server.
5. Generates `deploy/.env` with auto-generated secrets if missing.
6. Builds Docker images for backend (with FFmpeg pre-installed) and frontend.
7. Issues a **Let's Encrypt certificate** for `$DOMAIN` via HTTP-01.
8. Renders the nginx template with the real domain into a live config.
9. `docker compose up -d` brings the whole stack online.
10. Seeds the admin account in MongoDB.
11. Installs `streamhub.service` (systemd) so the stack auto-starts on reboot.
12. Prints a Navicat connection walkthrough.

## 4. Connect Navicat / Compass to MongoDB

MongoDB binds `127.0.0.1:27017` only — **not reachable from the internet**.
Use an **SSH tunnel** from your workstation.

### Navicat → New Connection → MongoDB

```
General tab
  Connection name:  StreamHub Prod
  Host:             127.0.0.1
  Port:             27017
  Database:         streamhub
  Authentication:   Password
  Username:         shadmin
  Password:         <MONGO_ROOT_PASSWORD from deploy/.env>
  Auth DB:          admin

SSH tab  (check "Use SSH Tunnel")
  Host:             <your VPS public IP>
  Port:             22
  User:             root  (or your sudo user)
  Authentication:   Password or Private Key
```

Click **Test Connection** → ✅ — then **OK**.

### MongoDB Compass

Same values; URI form:

```
mongodb://shadmin:YOUR_PASSWORD@127.0.0.1:27017/streamhub?authSource=admin
```

(URL-encode the password if it contains special characters.) Use Compass's
SSH tunnel pane with the same SSH credentials.

### Shell access (no GUI)

```bash
docker exec -it sh-mongo mongosh \
  -u shadmin -p "$(grep MONGO_ROOT_PASSWORD /opt/streamhub/deploy/.env | cut -d= -f2)" \
  --authenticationDatabase admin streamhub
```

## 5. Daily ops

```bash
# Logs
docker compose -f /opt/streamhub/deploy/docker-compose.yml logs -f
docker compose -f /opt/streamhub/deploy/docker-compose.yml logs -f backend

# Restart (picks up .env changes)
sudo systemctl restart streamhub

# Pull latest code + rebuild + restart
cd /opt/streamhub && git pull && sudo systemctl reload streamhub

# Reset admin password
sudo bash deploy/scripts/reset-admin.sh

# Mongo backup
sudo bash deploy/scripts/backup-mongo.sh
```

## 6. SSL renewal

The `certbot` container re-runs `certbot renew` every 12 h and reloads nginx
on success. No cron needed.

## 7. Uninstall

```bash
sudo systemctl disable --now streamhub
docker compose -f /opt/streamhub/deploy/docker-compose.yml --env-file /opt/streamhub/deploy/.env down -v
sudo rm /etc/systemd/system/streamhub.service
sudo rm -rf /opt/streamhub
sudo systemctl daemon-reload
```

`-v` also drops the Mongo data volume; omit it to preserve data.
